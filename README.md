ViaCEP

   📌 Sobre o projeto

Este projeto foi desenvolvido utilizando FlutterFlow e integra a API ViaCEP para realizar o preenchimento automático de endereços a partir do CEP informado.

O objetivo é facilitar o cadastro de usuários, reduzindo erros de digitação e proporcionando uma experiência mais rápida e eficiente.

   🚀 Funcionalidades

- Consulta de CEP em tempo real.
- Preenchimento automático de:
  - Rua
  - Bairro
  - Cidade
  - Estado
- Interface desenvolvida no FlutterFlow.
- Integração com API REST (ViaCEP).

    🛠️ Tecnologias utilizadas

- FlutterFlow
- Flutter
- Dart
- API ViaCEP

   🔗 API utilizada
 
https://viacep.com.br/

   📱 Objetivo

Este projeto foi desenvolvido para demonstrar a integração entre um aplicativo FlutterFlow e uma API pública, aplicando conceitos de consumo de APIs REST e automação de formulários.
